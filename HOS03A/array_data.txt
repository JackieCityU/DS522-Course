Challenge:
What are the primary risks to data integrity 
when flattening a NumPy array? Specifically, explain the 
difference between a 'view' and a 'copy', and how using. ravel() VS  .flatten() method  
can lead to accidental data mutation or memory errors.

=> The main data integrity risk when flattening is unintended 
sharing of memory. A view shares the original array’s data, 
so changing it can mutate the source. A copy has its own 
memory, so changes stay isolated. ravel() often returns 
a view, making it faster and more memory-efficient but 
riskier. flatten() always returns a copy, making it safer 
for modification but more memory-expensive.

Challenge answers:
Challenge: What are the primary use cases 
for multi-dimensional arrays, and why does NumPy’s 
contiguous memory 
allocation outperform Python's nested lists?"
Primary use cases of multi-dimensional array are data analysis, machine learning
image processing, scientific computing where data is structured in grids or matrices.

Why NumPy is faster:
NumPy arrays use contiguous memory allocation, allowing 
efficient CPU caching, vectorization, and execution in C code, whereas Python nested lists store elements as separate objects 
with pointers, leading to slower performance.
